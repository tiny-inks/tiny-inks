# Home page video loop

- `tiny-inks-loop.webm` — placeholder 6-second silent loop generated from a category photo. Replace it with a real 6–12 s clip of the shop / wrapping / products (VP8/VP9 `.webm`, or add an `.mp4` and point `VideoLoop` at it via the `src` prop). Keep it under ~1.5 MB.
- `poster.jpg` — first frame shown before playback and the only thing shown when the visitor prefers reduced motion. Swap it together with the clip (4:3, 1200×900 or larger).

The video is muted, autoplays, loops, and plays inline on phones. Nothing else needs changing.
